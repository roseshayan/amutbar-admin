# AmutBar Admin & API

پنل مدیریت و API مشترک اپ رانندگان و اپ اعلام بار.

راهنمای استقرار و چک‌لیست امنیتی در
[`DEPLOYMENT_FA.md`](DEPLOYMENT_FA.md) قرار دارد.

فایل‌های دیتابیس:

- `database/schema.sql`: ساختار پاک و بدون داده‌ی کاربران
- `database/reference_seed.sql`: فقط داده‌های عمومی استان، شهر، کالا و بارگیر
- `database/migrations/`: مهاجرت‌های افزایشی برای دیتابیس موجود

فایل `.env`، dump عملیاتی دیتابیس، لاگ‌ها، آپلود کاربران و کلیدها نباید در
بسته‌ی انتشار یا مخزن کد قرار گیرند.
